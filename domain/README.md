# Product KB

Thư mục này chứa knowledge base của một sản phẩm: manifest `domain.md` mười một mục và các file KB. Repo engine để trống thư mục này, chỉ có file README.

Đưa một sản phẩm vào quy trình: tạo repo riêng cho sản phẩm từ repo engine (`USER-GUIDE.md` mục A5), sau đó chạy `/new-domain`. Lệnh chép khung từ `engine/templates/domain/` sang đây, sau đó hỏi thông tin theo `DOMAIN-SETUP.md`.

Thư mục này thuộc phần riêng của sản phẩm: lấy bản engine mới không ghi đè nội dung ở đây.
