# Assets

Tài sản hình ảnh của sản phẩm để AI dùng khi làm UX Brief và UI.

| Thư mục hoặc file | Nội dung | Dùng ở |
|---|---|---|
| `theme/` | UI theme: file token, CSS, ảnh bảng màu và chữ, khi Figma chưa có biến | E2 |
| `screens/` | Ảnh màn mẫu của app đang chạy, mỗi pattern chính một ảnh | D2, E1 |
| `refs/` | Thư viện design ref đã dùng ở các màn L3, kèm ghi chú đã học gì | E1 |

Trống. Điền khi dựng domain.
